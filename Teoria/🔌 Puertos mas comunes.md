# 🌐 **Web**

- **HTTP** → `80`
    
- **HTTPS** → `443`
    
- **WebDAV / WebDisk** → `2077`
    
- **WebDAV / WebDisk (SSL)** → `2078`
    

---

## 📁 **Transferencia de archivos**

- **FTP** → `21`
    
- **FTPS (SSL/TLS)** → `990`
    
- **SFTP (sobre SSH)** → `22`
    

📌 _Nota_:

- **SFTP ≠ FTPS**
    
- SFTP usa **SSH (22)**
    

---

## 🔐 **Acceso remoto**

- **SSH** → `22`
    

---

## 📨 **Correo electrónico**

- **SMTP** → `25`
    
- **SMTP (alternativo)** → `26`
    
- **SMTP (alternativo)** → `2525`
    
- **SMTP Submission (STARTTLS)** → `587`
    
- **POP3** → `110`
    
- **POP3 (SSL)** → `995`
    
- **IMAP** → `143`
    
- **IMAP (SSL)** → `993`

## 🗄️ **Bases de datos**
