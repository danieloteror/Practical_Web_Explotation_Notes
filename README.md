Este repositorio contiene una guía completa de vulnerabilidades web, orientada a CTFs, pentesting y bug bounty, con un enfoque práctico, técnico y explotable.

El contenido está diseñado específicamente para ser descargado e importado en Obsidian, aprovechando al máximo:
- enlaces internos [[ ]]
- índices estructurados
- organización por notas
- flujo de estudio progresivo

No es teoría académica:
Es material pensado para atacar, entender y explotar vulnerabilidades reales.

🎯 Objetivo del repositorio

- Servir como base de conocimiento personal de seguridad web
- Tener chuletas rápidas durante CTFs
- Entender cómo y por qué ocurren las vulnerabilidades
- Aprender a enumerar, explotar y validar impacto
- Centralizar técnicas modernas usadas en entornos reales

Uso recomendado (Obsidian)
Clona el repositorio:
- git clone https://github.com/danieloteror/Practical_Web_Explotation_Notes.git

Abre Obsidian
Selecciona Open folder as vault
Apunta a la carpeta del repositorio
